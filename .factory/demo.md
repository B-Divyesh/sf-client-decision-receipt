# Demo sandbox

Open [`/demo`](https://client-decision-receipt.sociobot.in/demo), or select
**Try it with sample data** from the first screen.

The demo loads Fern Studio's realistic "Spring website refresh" request for
Moss & Morning. It includes a planning workshop, homepage design, and build
handoff. You can record any of the three client decisions and inspect the
resulting dated receipt seal.

Each visit provisions a random backend demo workspace that is separate from
the `proposals` and `deliveries` tables. It expires within 24 hours and never
queues mail. **Reset demo** deletes that workspace and starts a new sample.
**Start for real** returns to the normal proposal form. The persistent banner
states this boundary while the sample is open.
